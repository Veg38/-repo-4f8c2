Components and connectivity

Find the component or signal you need at the bench

Search by reference, value, package or net name, then highlight the matching board data. AGBoard keeps logical connectivity and physical copper inspection close together.

Watch the video

From a reference name to its place on the board

Component data is read from supported Gerber X3, KiCad, Altium, ODB++, Eagle and BoardView files. Placement files can supplement formats that do not carry assembly information.

Named nets from ODB++, IPC-2581, IPC-D-356 and BoardView can be searched directly. For ordinary copper geometry, AGBoard can also trace physically connected shapes without a netlist.

What you can inspect

Component search

Filter references, values and packages, then centre and highlight the selected component.

Named nets

Find signals such as GND or VCC and highlight their associated pads, pins and test points.

Copper trace

Tap supported copper geometry to follow physical connectivity when no logical netlist is available.

What you can do

  • Locate a reference such as C1, U12 or TP4
  • Review component value, package, side and rotation when available
  • Separate top-side and bottom-side component highlights
  • Find all pads and test points belonging to a BoardView net
  • Search logical nets carried by ODB++, IPC-2581 or IPC-D-356
  • Follow connected copper across visible layers

Frequently asked questions

Does every file contain component names?

No. AGBoard displays component information when the format carries it or when a compatible placement file is imported.

Can I search a net without IPC-D-356?

Yes when the source format already carries named nets, including supported ODB++, IPC-2581, KiCad, Altium and BoardView data.

What happens when there is no netlist?

AGBoard can trace supported copper shapes by geometric connectivity, which is different from inventing logical net names.
